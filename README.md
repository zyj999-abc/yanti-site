# 研题岛真题网（纯前端演示站）

一个可直接部署到 **GitHub Pages** 的考研真题刷题站点，参考「研可岸真题网」的信息架构与暖橙色视觉风格实现。无需服务器、无需构建工具，所有数据与依赖都已内置。

> 站内题目均为**原创示例题**，仅用于展示交互与排版，不是真实考研真题，也不构成任何备考依据。

## 功能

- **首页**：科目卡片（数学一/二/三、408、英语一/二）、年份试卷入口、学习数据概览。
- **学习空间**：按科目展开考点树、考点掌握度、答题趋势折线图、科目占比环形图。
- **题目详情**：选项作答、查看答案与解析、标记掌握程度、收藏、加入错题本、笔记、评论、上一题/下一题、打印本题。
- **组合刷题**：从题库随机抽题，计时、答题卡、交卷统计、主观题自评，练习记录自动保存。
- **年份试卷**：按年份和科目浏览整卷，支持整卷练习与打印（含答案）。
- **错题本 / 收藏**：按科目、题型、关键词筛选，支持移除和全部重刷。
- **智能组卷**：按科目、考点、题型、年份、题量随机组卷，可预览、移除、保存、打印、开始练习；支持按 **2026 考研标准卷型**（数学一/二/三、408、英语一/二）自动拼卷，并选择 **易 / 中 / 难**。
- **PDF 题库导入**：上传带文字层的 PDF，在浏览器本地拆题，自动识别题型、考点、分值、难度与答案；可逐题校对后入库，并参与组卷和刷题。
- **学习报告**：练习次数、答题量、正确率、错题数、考点掌握度、最近练习、科目统计、组卷记录、导出 JSON、清除数据。
- **全局搜索**：`Ctrl/Cmd + K` 或顶部搜索按钮，支持回车打开第一条结果。
- **移动端适配**：抽屉导航、单栏题目页、响应式报表与表格。
- 公式使用 KaTeX 渲染，图表为手写 SVG，不依赖第三方图表库。

## 本地预览

由于页面使用相对路径和 hash 路由，直接双击 `index.html` 也能打开；若浏览器限制本地文件，可在目录内启动一个静态服务：

```bash
cd yanti-site
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库（例如 `yanti-site`）。
2. 把本目录下的**全部文件**（不是外层文件夹）推送到仓库默认分支：

   ```bash
   cd yanti-site
   git init
   git add .
   git commit -m "feat: 研题岛真题网静态站点"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 打开仓库 **Settings → Pages**，在 *Build and deployment* 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

说明：

- 站点全部使用相对路径与 hash 路由（`#/question/q1`），放在仓库子路径下也能正常访问，不需要改配置。
- `.nojekyll` 已包含，避免 GitHub Pages 的 Jekyll 处理忽略以下划线开头的文件。
- 若绑定自定义域名，在仓库根目录添加 `CNAME` 文件即可。

## 数据与本地存储

- 题库位于 `assets/js/data.js`，结构为 `window.APP_DATA = { subjects, questions, ... }`，可直接替换或追加题目。
- 学习记录（练习、错题、收藏、笔记、评论、组卷）保存在浏览器 `localStorage` 的 `yantidao_state_v1` 键中，**仅保存在当前浏览器**，换设备或清理缓存后会丢失。
- PDF 导入的题目与截图保存在浏览器 **IndexedDB**（`yantidao_imports_v1`）中；当浏览器不支持 IndexedDB 时，自动退化为 `localStorage`（`yantidao_imported_v1`，只存题目文本，不含截图），并受浏览器配额限制。
- 「学习报告 → 导出学习数据」可导出 JSON 备份。
- 当前题量：478 道（数学一 148、数学二 104、数学三 108、408 86、英语一 16、英语二 16），不含你导入的 PDF 题目。

## PDF 导入与标准组卷

### 使用流程

1. 打开「导入题库」，选择科目、年份和默认难度。
2. 上传带文字层的 PDF（单个不超过 30 MB），等待浏览器本地解析。
3. 在「校对题目」中检查题型、考点、难度、分值、选项和答案；可批量修改，也可单题展开编辑、移除。
4. 点击「导入 N 道题」，题目会立即进入题库，可在「智能组卷」中选择「仅我导入的 PDF 题」抽题。
5. 组卷时选择「数学二 · 最新标准卷」等卷型，再选择易/中/难。题库不足时会自动放宽难度并在预览中标出「难度放宽」。

### 识别规则

- **题型**：按大题标题和 A–D 选项识别选择题、填空题、解答题、证明题；英语另支持完形填空、阅读理解、新题型、翻译、写作；408 支持综合应用题。
- **考点**：用题干关键词匹配现有考点树。数学二会自动过滤概率论、无穷级数与空间解析几何，避免出现不考的考点。
- **分值**：优先读取「本题满分 N 分 / （N 分）」；否则按题型和科目给默认值。英语小作文 10 分、大作文 20/15 分。
- **难度**：按题型、题干长度和关键词粗判易/中/难，导入前可改，组卷时按难度筛选。
- **答案**：识别 `【答案】`、`【解析】`、`答案：` 以及卷末「参考答案」；识别不到时留空，不编造答案。
- **截图**：数学、408 默认保留原题截图，公式和图形以原卷图片显示；英语不生成截图，按文字与选项排版。
- **阅读材料**：英语完形、阅读、新题型会把题目前的段落自动挂到该组题目上。

### 标准卷结构

| 卷型 | 结构 |
| --- | --- |
| 数学一 / 二 / 三 | 选择 10×5=50，填空 6×5=30，解答 6 题=70（10/10/10/10/15/15），满分 150 |
| 408 | 单选 40×2=80，综合应用题 7 题=70（10/15/8/13/7/8/9），满分 150 |
| 英语一 | 完形 20×0.5=10，阅读 20×2=40，新题型 5×2=10，翻译 5×2=10，写作 10+20=30，满分 100 |
| 英语二 | 完形 20×0.5=10，阅读 20×2=40，新题型 5×2=10，翻译 15，写作 10+15=25，满分 100 |

### 已知边界

- 只支持**带文字层**的 PDF；扫描版需要先用 OCR 转成可选中文字的 PDF。
- 数学公式的文本层常常是乱码或拆散的符号，所以数学默认用原题截图展示；截图模式下题干文本不重复显示。
- 英语阅读材料是按题目前的连续段落自动关联的，遇到跨页、双栏或图片题可能需要手动校对。
- 答案识别依赖清晰的标签或卷末答案区；没有答案区时答案会留空。
- 拆题是启发式规则，不同机构的排版差异较大，导入前的校对步骤是必要的。
- 所有解析和存储都在浏览器本地完成，文件不会上传到任何服务器。

## 自定义

- **品牌名**：搜索 `研题岛`，集中替换 `index.html`、`assets/js/core.js`、页脚与 README 中的文案。
- **主题色**：修改 `assets/css/app.css` 顶部的 `--orange`、`--orange-strong`、`--bg` 等 CSS 变量。
- **首页文案**：`assets/js/views-home.js`。
- **新增科目**：在 `data.js` 的 `subjects` 中追加对象，并为题目设置对应的 `subject`、`kpId`。

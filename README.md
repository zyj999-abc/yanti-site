# 研题岛 ATLAS（纯前端演示站）

> 每一道题，都有它的坐标。

一个可直接部署到 **GitHub Pages** 的考研刷题站点。无需服务器、无需构建工具，题库、PDF 解析、组卷、练习记录全部在浏览器本地完成。

视觉与交互为独立设计：深森林色固定侧栏、骨白坐标纸背景、酸性青柠强调色，以及以「地形 / 坐标」为核心的首页与导航系统；不复制任何现有网站的品牌、配色或页面结构。

> 站内题目均为**原创示例题**，仅用于展示交互与排版，不是真实考研真题，也不构成任何备考依据。

## 设计语言

- **主题**：把题库看成一张地形图。每个科目是一块地形，每道题有自己的坐标（科目 · 年份 · 题号），练习是在图上留下轨迹。
- **色彩**：深森林 `#10231d`（导航与主操作）、骨白纸 `#f3f1e8`（页面底色）、酸性青柠 `#d9ff59`（定位与强调）、陶土 `#bf6741`（数据与图表）、鼠尾草绿与灰蓝（辅助分类）。
- **桌面布局**：238px 固定左侧 rail（品牌、编号导航、本地档案）+ 66px 固定工作栏（当前页坐标、全局搜索、导入入口）。
- **移动布局**：固定顶部品牌栏 + 五栏底部 tab（总览、考点、组卷、导入、错题）+ 深色抽屉导航。
- **组件**：编号式导航、坐标位置卡、地形行、年份条带、操作台、题目卡、答题卡、标准卷结构表。全部为手写 CSS，无 UI 框架与图标库。
- **无障碍与适配**：语义化标签、可见键盘焦点、`prefers-reduced-motion` 降级；断点覆盖 1600 → 320px，无横向溢出。

## 功能

- **总览**：地形化首页，显示当前科目坐标、题库统计、科目地形、最近年份档案与常用操作台。
- **考点地图**：按科目展开考点树、考点掌握度、答题趋势折线图、题型分布环图；支持按题型筛选和组合练习。
- **年份档案**：按年份与科目浏览整卷，支持整卷练习与打印（可含答案）；年份侧栏显示题量与分值。
- **组合练习**：计时、答题卡、上一题/下一题、主观题自评、交卷统计、练习记录与错题自动归档。
- **题目详情**：选项作答、查看答案与解析、标记掌握程度、收藏、加入错题本、笔记、讨论、前后题跳转、打印本题。
- **错题本**：按科目、题型、关键词筛选，支持移除、重刷与导出。
- **智能组卷**：自由组卷（科目 / 考点 / 题型 / 年份 / 题量）或按 **2026 考研标准卷型**（数学一/二/三、408、英语一/二）自动拼卷，难度支持 **易 / 中 / 难**，题库不足时自动放宽并在预览中标出。
- **PDF 题库导入**：上传带文字层的 PDF，在浏览器本地拆题，自动识别题型、考点、分值、难度与答案；逐题校对后入库，参与组卷与练习。
- **学习档案**：练习次数、答题量、正确率、错题数、考点掌握度、最近练习、科目统计、组卷记录、导出 JSON、清除数据。
- **全局搜索**：`Ctrl/Cmd + K` 或顶部搜索入口，回车打开第一条结果。
- **本地优先**：无后端、无账号、无上传；关闭页面后数据仍留在当前浏览器。

## 本地预览

页面使用相对路径和 hash 路由，直接双击 `index.html` 也能打开；若浏览器限制本地文件，可在目录内启动静态服务：

```bash
cd yanti-site
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库（例如 `yanti-site`）。
2. 把本目录下的**全部文件**（不是外层文件夹）推送到仓库默认分支：

   ```bash
   cd yanti-site
   git init
   git add .
   git commit -m "feat: 研题岛 ATLAS 学习地图"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 打开仓库 **Settings → Pages**，在 *Build and deployment* 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

说明：

- 全部使用相对路径与 hash 路由（`#/question/q1`），放在仓库子路径下也能正常访问。
- `.nojekyll` 已包含，避免 GitHub Pages 的 Jekyll 处理忽略以下划线开头的文件。
- 若绑定自定义域名，在仓库根目录添加 `CNAME` 文件即可。

## 数据与本地存储

- 题库位于 `assets/js/data.js`，结构为 `window.APP_DATA = { subjects, questions, ... }`，可直接替换或追加题目。
- 学习记录（练习、错题、收藏、笔记、评论、组卷）保存在 `localStorage` 的 `yantidao_state_v1` 键中，**仅保存在当前浏览器**。
- PDF 导入的题目与截图保存在 **IndexedDB**（`yantidao_imports_v1`）；浏览器不支持 IndexedDB 时退化为 `localStorage`（`yantidao_imported_v1`，只存题目文本，不含截图）。
- 「学习档案 → 导出学习数据」可导出 JSON 备份。
- 当前题量：478 道（数学一 148、数学二 104、数学三 108、408 86、英语一 16、英语二 16），不含你导入的 PDF 题目。

## PDF 导入与标准组卷

### 使用流程

1. 打开「PDF 导入」，选择科目、年份和默认难度。
2. 上传带文字层的 PDF（单个不超过 30 MB），等待浏览器本地解析。
3. 在「校对题目」中检查题型、考点、难度、分值、选项和答案；可批量修改，也可单题编辑、移除。
4. 点击「导入 N 道题」，题目立即进入题库；组卷时可选择「仅我导入的 PDF 题」。
5. 组卷时选择「数学二 · 最新标准卷」等卷型，再选择易/中/难。题库不足时自动放宽难度，并在预览中标出「难度放宽」。

### 识别规则

- **题型**：按大题标题与 A–D 选项识别选择题、填空题、解答题、证明题；英语另支持完形填空、阅读理解、新题型、翻译、写作；408 支持综合应用题。
- **考点**：用题干关键词匹配现有考点树。数学二自动过滤概率论、无穷级数与空间解析几何。
- **分值**：优先读取「本题满分 N 分 / （N 分）」；否则按题型和科目给默认值。英语小作文 10 分、大作文 20/15 分。
- **难度**：按题型、题干长度和关键词粗判易/中/难，导入前可改，组卷时按难度筛选。
- **答案**：识别 `【答案】`、`【解析】`、`答案：` 以及卷末「参考答案」；识别不到时留空，不编造答案。
- **清洗**：自动移除字体私有区字符、控制符/零宽字符、替换符、断码符号、页眉页脚、重复水印、斜向/旋转水印，以及网址、QQ/微信、机构联系方式和「内部资料 / 禁止传播」一类字样；校对页会显示过滤统计。
- **质量检测**：文字层缺失或中文识别率异常时会提示，并自动打开「保留原题截图」；扫描版仍需先 OCR。
- **截图去水印**：检测到正文水印时，会对浅灰色、低饱和度的水印笔画做淡化，黑色公式与图形不受影响；深色或彩色图章式水印可能残留。
- **截图**：数学、408 默认保留原题截图，公式和图形以原卷图片显示；英语不生成截图，按文字与选项排版。
- **阅读材料**：英语完形、阅读、新题型会把题目前的段落自动挂到该组题目上。

### 标准卷结构

| 卷型 | 结构 |
| --- | --- |
| 数学一 / 二 / 三 | 选择 10×5=50，填空 6×5=30，解答 6 题=70（10/10/10/10/15/15），满分 150 |
| 408 | 单选 40×2=80，综合应用题 7 题=70（10/15/8/13/7/8/9），满分 150 |
| 英语一 | 完形 20×0.5=10，阅读 20×2=40，新题型 5×2=10，翻译 5×2=10，写作 10+20=30，满分 100 |
| 英语二 | 完形 20×0.5=10，阅读 20×2=40，新题型 5×2=10，翻译 15，写作 10+15=25，满分 100 |

### 已知边界

- 只支持**带文字层**的 PDF；扫描版需要先用 OCR 转成可选中文字的 PDF。
- 数学公式的文本层常常是乱码或拆散的符号，所以数学默认用原题截图展示；截图模式下题干文本不重复显示。
- 水印清理基于文字层特征（重复、旋转、页眉页脚、联系方式等）和浅色像素淡化，无法保证去除所有图片/矢量水印；水印与题干重叠时请以校对结果为准。
- 若 PDF 使用了损坏的自定义字体编码，文字层可能整体不可读；此时会提示并建议改用 OCR 版本或直接使用原题截图。
- 英语阅读材料按题目前的连续段落自动关联，跨页、双栏或图片题可能需要手动校对。
- 答案识别依赖清晰的标签或卷末答案区；没有答案区时答案会留空。
- 拆题是启发式规则，不同机构的排版差异较大，导入前的校对步骤是必要的。
- 所有解析和存储都在浏览器本地完成，文件不会上传到任何服务器。

## 自定义

- **品牌名**：搜索 `研题岛` / `ATLAS`，集中替换 `index.html`、`assets/js/core.js`、页脚与 README 中的文案。
- **主题色与组件**：修改 `assets/css/atlas.css` 顶部的 `--forest`、`--lime`、`--paper`、`--clay` 等变量；旧组件样式在该文件后半部分统一覆盖。
- **布局尺寸**：`--rail-w`、`--bar-h`、`--mobile-bar-h`、`--tabs-h` 分别控制桌面侧栏、桌面工作栏、移动顶栏与底部 tab 高度。
- **首页地形与文案**：`assets/js/views-home.js`。
- **新增科目**：在 `data.js` 的 `subjects` 中追加对象，并为题目设置对应的 `subject`、`kpId`。
